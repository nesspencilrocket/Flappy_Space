# PlappySpace 🚀

Godotエンジンを使用して作成した、Flappy Birdライクなアクションゲームである。
迫りくる障害物をタイミングよく避け、ハイスコアを目指す。

## 🎮 操作方法 (Controls)

直感的なキーボード操作でプレイ可能。

* **Spaceキー** : ジャンプ（上昇）
* **Aキー** : 左へ移動
* **Dキー** : 右へ移動

> **Tip**: 上下のジャンプだけでなく、左右の移動（A/D）をうまく駆使して障害物の隙間を潜り抜けるのが攻略の鍵となる。

## ✨ 特徴 (Features)

* **シンプルで中毒性のあるゲームプレイ**: Flappy Birdでおなじみの、何度もリトライしたくなる難易度となっている。
* **拡張された操作性**: 通常のジャンプに加え、左右移動ができるため、より自由度の高いアクションを楽しめる。
* Godot Engineによるスムーズな動作、たぶん。
